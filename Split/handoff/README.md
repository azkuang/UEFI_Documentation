# Handoff Directory

This directory contains session handoff documents.

## Purpose

When you ask for a handoff, a new `handoff_YYYY-MM-DD_<topic>.md` is written here.
Paste the contents into a new Claude Code session to give it full context on the
current problem, what has been tried, and what to do next.

## Convention

- One file per handoff
- Named `handoff_YYYY-MM-DD_<short-topic>.md`
- Each file is self-contained — a new agent needs no other context to continue the work
